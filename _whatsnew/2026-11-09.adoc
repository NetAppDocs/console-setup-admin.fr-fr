=== Agent Console 4.13.0

La version 4.13.0 prend en charge à la fois le mode standard et le mode restreint.

Cette version de l'agent Console inclut des améliorations de sécurité et des corrections de bugs, ainsi que la fonctionnalité nouvelle suivante.

.Créez automatiquement le rôle de déploiement AWS lors du déploiement d’un agent Console
Vous n'avez plus besoin de créer le rôle IAM pour déployer un Console agent dans AWS avant de commencer. La NetApp Console peut créer ce rôle pour vous. link:https://docs.netapp.com/us-en/console-setup-admin/task-install-agent-aws-console.html["Découvrez comment déployer un agent Console dans AWS depuis la Console"^]
