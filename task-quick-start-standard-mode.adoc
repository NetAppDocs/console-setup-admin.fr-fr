= Démarrage rapide pour NetApp Console en mode standard
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Commencez à utiliser la NetApp Console (SaaS) en préparant le réseau pour la console, en vous inscrivant et en créant un compte, puis en utilisant l'assistant de la console pour configurer les fonctionnalités initiales.

Vous accédez à une console Web hébergée en tant que produit logiciel en tant que service (SaaS) de NetApp. Vous pouvez utiliser la console pour gérer votre environnement de stockage cloud hybride et utiliser les services de données NetApp .

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"] link:reference-networking-saas-console.html["Préparez le réseau pour l'utilisation de la NetApp Console"]
[role="quick-margin-para"]
Assurez-vous que les ordinateurs accédant à la NetApp Console disposent d'un accès réseau aux points de terminaison requis.

link:reference-networking-saas-console.html["Apprenez comment préparer le réseau pour la NetApp Console."]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"] link:task-sign-up-saas.html["Inscrivez-vous et créez une organisation"]
[role="quick-margin-para"]
Rendez-vous sur le  https://console.netapp.com["NetApp Console"^] et inscrivez-vous. Si l'on vous demande de créer une organisation et que vous pensez qu'une organisation existe déjà pour votre entreprise, fermez la boîte de dialogue et informez-en l'administrateur de votre organisation. S'il n'y a pas actuellement d'administrateur d'organisation pour votre entreprise, vous pouvez revendiquer ce rôle. link:task-user-settings.html#contact-admin["Apprenez comment contacter un administrateur de l'organisation."^]

[role="quick-margin-para"]
À ce stade, vous êtes connecté et pouvez utiliser l’assistant NetApp pour commencer à configurer la Console. Pour commencer, associez votre compte NetApp Support Site et un agent Console afin d’activer la fonctionnalité complète.

Si vous choisissez de ne pas utiliser l'assistant NetApp ou d'installer un agent Console, vous pouvez commencer à gérer le stockage et à utiliser des services tels que Digital Advisor, Amazon FSx for ONTAP, Azure NetApp Files, et bien plus encore. link:concept-agents.html["Découvrez ce que vous pouvez faire sans agent de console"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"] Associez votre compte NetApp Support Site (NSS).
L'association de votre compte NetApp Support Site (NSS) à la console vous permet de gérer plus facilement vos licences et abonnements et d'accéder aux ressources d'assistance directement depuis la console.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"] Créer un agent de console
[role="quick-margin-para"]
Les fonctionnalités avancées de gestion du stockage et certains services de données NetApp nécessitent l'installation d'un agent de console.  L'agent de console permet à la console de gérer les ressources et les processus au sein de votre environnement cloud hybride.

[role="quick-margin-para"]
Vous pouvez créer un agent de console dans votre réseau cloud ou sur site.

[role="quick-margin-list"]
* link:concept-agents.html["En savoir plus sur les cas où les agents de console sont requis et leur fonctionnement"]
* link:concept-install-options-aws.html["Découvrez comment créer un agent de console dans AWS"]
* link:concept-install-options-azure.html["Découvrez comment créer un agent de console dans Azure"]
* link:concept-install-options-google.html["Découvrez comment créer un agent de console dans Google Cloud"]
* link:task-install-agent-on-prem.html["Découvrez comment créer un agent de console sur site"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinq"] Ajouter un système de stockage à la console
[role="quick-margin-para"]
Dans la NetApp Console, vous pouvez ajouter ou découvrir des systèmes de stockage pour gérer votre environnement de stockage cloud hybride. Utilisez l'assistant NetApp pour ajouter votre premier système de stockage.


TIP: Si vous installez un agent Console dans AWS, Microsoft Azure ou Google Cloud, la Console détecte automatiquement les informations relatives aux compartiments Amazon S3, au stockage Blob Azure ou aux compartiments Google Cloud Storage à l'emplacement où l'agent est installé. Ces systèmes sont automatiquement ajoutés à la page *Systèmes*.

* link:https://docs.netapp.com/us-en/storage-management-ontap-onprem/task-discovering-ontap.html["Apprenez à découvrir un système ONTAP"]
* link:https://docs.netapp.com/us-en/storage-management-storagegrid/task-discover-storagegrid.html["Découvrez comment utiliser un système StorageGRID"]
* link:https://docs.netapp.com/us-en/storage-management-e-series/task-discover-e-series.html["Découvrez comment découvrir un système de la série E"]


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Six"] link:task-subscribe-standard-mode.html["Abonnez-vous aux NetApp Intelligent Services (facultatif)"]
[role="quick-margin-para"]
Souscrivez aux NetApp Intelligent Services auprès de votre fournisseur de cloud pour une facturation horaire (PAYGO) ou annuelle. Un abonnement inclut NetApp Backup and Recovery, Cloud Volumes ONTAP, NetApp Ransomware Resilience, NetApp Disaster Recovery, et NetApp Data Classification.

[NOTE]
====
NetApp Cloud Tiering n'est plus disponible à l'achat ni au renouvellement de licence depuis le 26 avril 2026.

Les clients existants peuvent continuer à utiliser et à bénéficier du support pour NetApp Cloud Tiering jusqu'à l'expiration de leur abonnement ou de leur contrat de licence. Après l'expiration de l'abonnement, les clients n'auront plus accès aux fonctionnalités ou au support de NetApp Cloud Tiering.

NetApp recommande aux clients de collaborer avec leur représentant NetApp pour convertir leurs licences de hiérarchisation existantes en licences FabricPool ONTAP, qui offrent la fonctionnalité de hiérarchisation des données dans ONTAP. Pour plus d'informations sur la configuration de la hiérarchisation des données dans ONTAP à l'aide de FabricPool, voir link:https://docs.netapp.com/us-en/ontap/fabricpool/install-license-aws-azure-ibm-task.html["Installez une licence FabricPool sur un cluster ONTAP"^].
