= Démarrage rapide pour NetApp Console en mode privé
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Vous pouvez installer NetApp Console sur site ou dans un environnement cloud sécurisé. Le mode privé est généralement utilisé avec les environnements sur site sans connexion Internet et avec les régions cloud sécurisées, qui incluent  https://aws.amazon.com/federal/secret-cloud/["AWS Secret Cloud"^],  https://aws.amazon.com/federal/top-secret-cloud/["AWS Top Secret Cloud"^] et  https://learn.microsoft.com/en-us/azure/compliance/offerings/offering-dod-il6["Azure IL6"^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"] link:task-prepare-private-mode.html["Préparez-vous au déploiement"]
[role="quick-margin-list"]
. Préparez un hôte Linux dédié qui répond aux exigences en matière de CPU, de RAM, d’espace disque, d’outil d’orchestration de conteneurs, etc.
. Configurez la mise en réseau qui permet d'accéder aux réseaux cibles.
. Pour les déploiements dans le cloud, configurez les autorisations dans votre fournisseur de cloud afin de pouvoir associer ces autorisations à l'agent Console après avoir installé le logiciel.


.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"] link:task-install-private-mode.html["Déployer l'agent de console"]
[role="quick-margin-list"]
. Installez l'agent Console sur votre propre hôte Linux.
. Configurez la NetApp Console en ouvrant un navigateur Web et en saisissant l'adresse IP de l'hôte Linux.
. Pour les déploiements dans le cloud, fournissez à la NetApp Console les autorisations que vous avez précédemment configurées.

Le tableau suivant répertorie les fonctionnalités de gestion du stockage, les services de données et les fonctionnalités d'administration disponibles dans la NetApp Console lorsque vous l'installez en mode privé. Les fonctionnalités diffèrent lorsque vous installez la NetApp Console dans le cloud par rapport à vos locaux.
