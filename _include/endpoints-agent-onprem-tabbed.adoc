.Points de terminaison minimum requis
--
Ces points de terminaison sont nécessaires pour tous les déploiements d'agents Console. Des points de terminaison supplémentaires sont requis pour gérer les ressources NetApp dans AWS ou Azure.

[cols="2a,1a"]
|===
| Points de terminaison | Objectif Directive non résolue dans <stdin> - include::endpoints-agent.adoc[tag=nss-endpoints] Directive non résolue dans <stdin> - include::endpoints-agent.adoc[tag=saas-endpoints] Directive non résolue dans <stdin> - include::endpoints-agent.adoc[tag=upgrade-endpoints] 
|===

Lorsque l'agent Console est installé sur site, il a besoin d'un accès réseau aux points de terminaison AWS supplémentaires suivants pour gérer les systèmes NetApp (tels que Cloud Volumes ONTAP) déployés dans AWS.
