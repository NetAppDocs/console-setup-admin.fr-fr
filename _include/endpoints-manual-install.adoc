Les points de terminaison listés dans l'option 1 sont recommandés car ils offrent une sécurité accrue. Nous vous recommandons de configurer votre pare-feu pour autoriser les points de terminaison listés dans l'option 1, tout en bloquant ceux listés dans l'option 2. Veuillez noter les points suivants concernant ces points de terminaison : ** Les points de terminaison listés dans l'option 1 sont pris en charge à partir de la version 3.9.47 de l'agent Console. Aucune compatibilité ascendante avec les versions précédentes de l'agent Console n'est assurée. ** L'agent Console contacte d'abord les points de terminaison listés dans l'option 2. Si ces points de terminaison ne sont pas accessibles, l'agent Console contacte automatiquement les points de terminaison listés dans l'option 1. ** Les points de terminaison de l'option 1 ne sont pas pris en charge si vous utilisez l'agent Console avec NetApp Backup and Recovery ou NetApp Ransomware Resilience. Dans ce cas, vous pouvez bloquer les points de terminaison listés dans l'option 1, tout en autorisant ceux listés dans l'option 2.

L'hôte peut essayer de mettre à jour les packages du système d'exploitation pendant l'installation.  L'hôte peut contacter différents sites de mise en miroir pour ces packages de système d'exploitation.
